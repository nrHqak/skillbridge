C#
public abstract class BasePost { public int Id { get; set; } public User Author { get; set; } public abstract string GetDisplayText(); } // Полиморфизм ↓ public class OfferPost : BasePost { public override string GetDisplayText() => $"[ПРЕДЛАГАЮ] {Category}"; }
Наследование
OfferPost и RequestPost наследуют BasePost — общие поля Id, Author, Category, CreatedAt, IsActive
Инкапсуляция
Все поля — публичные свойства (get; set;). Логика DataStore скрыта в статических методах
Полиморфизм
abstract GetDisplayText() — разный вывод для OfferPost и RequestPost без проверки типа
Минимум 2 класса-наследника
OfferPost + RequestPost → критерий выполнен ✓
