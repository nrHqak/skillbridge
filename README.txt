SkillBridge — платформа для обмена навыками внутри сообщества.
Приложение позволяет публиковать объявления о навыках,
находить взаимные совпадения и общаться в чате.

Запуск: открыть SkillBridgeApp.csproj в Visual Studio 2022, нажать F5.
Требования: .NET 6 или .NET 8, Windows.

Функции:
- Регистрация и вход пользователей
- Лента объявлений с фильтрацией по категории и поиском по ключевым словам
- Публикация новых объявлений (предложение навыка или поиск навыка)
- Алгоритм поиска взаимных совпадений между пользователями
- Встроенный чат для общения между пользователями
- Система рейтингов и отзывов
